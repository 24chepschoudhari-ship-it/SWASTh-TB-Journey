# iGEM integration handoff — SWASTh-TB TB Journey

## What this package is

This folder is a self-contained static web app for GitHub Pages. It uses local HTML, CSS and JavaScript files and does not load external fonts, scripts, images, stylesheets or CDNs. Its About screen links to public WHO resources, but those links are only requested if a visitor opens them.

## Before adding it to the official iGEM 2026 wiki

- The current iGEM wiki workflow requires the assets a wiki loads to be served from iGEM infrastructure; consult the official wiki deliverables guide.
- Do not embed this GitHub Pages URL as an external iframe or make the official wiki load the CSS/JavaScript directly from GitHub Pages. Adapt the source into your team's official wiki repository and use the approved asset/upload flow if the experience must run within the iGEM wiki.
- Use the official iGEM Attributions Form and disclose AI assistance as required by the 2026 AI policy. This README or the included AI note does not replace the official form.
- Have team members verify scientific claims, translations, accessibility, every gameplay branch, and the scoring assignments. The score is a teaching aid, not a clinical measure. The story scenes are currently in English; only the interface/navigation text is translated into Hindi, Marathi and Gujarati.
- Do not present the proposed biosensor as clinically validated or claim educational impact without data.
