# AI assistance and attribution note — team review required

This is a draft record for the SWASTh-TB team to review and update before publication. It is not a substitute for the official iGEM AI policy or attribution form.

## Assistance used in this build

OpenAI ChatGPT was used as an AI assistant during this build to help with CSS styling, responsive layout, accessibility markup, interface copy, JavaScript implementation of scene-progress, choice review, scoring and navigation, and code review. Team members remain responsible for reviewing, understanding, testing and approving the final code and content. No AI-generated artwork or new externally sourced images were added in this visual refresh. No external fonts, JavaScript libraries, icon libraries, or CDNs were added.

The existing story scenes, role definitions, four-choice branching structure, and proposed biosensor pathway were retained. The updated code adds scene-exploration tracking, choice review, a score for each answer and a score summary, accessibility improvements, replay/navigation controls, and a visible sources panel. The scoring rubric was drafted with AI assistance and is documented in `SCORING_RUBRIC.md`. It should be reviewed by the team before publication because the ratings are educational judgements, not validated clinical measures. These are software and interface changes; they are not evidence of clinical performance or educational impact.
