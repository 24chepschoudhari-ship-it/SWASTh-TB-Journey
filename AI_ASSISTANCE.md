## Assistance used in this build

OpenAI ChatGPT was used as an AI assistant during this build to help with CSS styling, responsive layout, accessibility markup, interface copy, JavaScript implementation of scene-progress, choice review, scoring and navigation, and code review. Team members remain responsible for reviewing, understanding, testing and approving the final code and content. No AI-generated artwork or new externally sourced images were added in this visual refresh. No external fonts, JavaScript libraries, icon libraries, or CDNs were added. 
The existing story scenes, role definitions, four-choice branching structure, and proposed biosensor pathway are all ideated by the igem team.
