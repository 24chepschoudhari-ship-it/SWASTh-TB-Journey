# SWASTh-TB — The TB Journey

The TB Journey is an interactive TB-awareness game made for the SWASTh-TB project by iGEM ICT Mumbai 2026. Players can explore the story from different points of view, make choices, read the feedback, and see a score at the end.

## Files

- `index.html` — the page
- `style.css` — the design and responsive layout
- `game.js` — story navigation, choices and scoring
- `content.js` — interface text for the available languages
- `manifest.webmanifest` — web app metadata
- `404.html` — simple page for missing links

## Run it

Open `index.html` in a browser, or publish the files with GitHub Pages. Keep all files together in the same repository root; the paths in the HTML expect this layout.

The game is for education only. It does not diagnose TB or replace advice from a qualified health professional. The SWASTh-TB sensing concept shown in the game is proposed research, not a clinically validated diagnostic.
