# Deployment

## Run and deploy the standalone simulator

1. Extract the ZIP.
2. Open `index.html` locally and test the full experience.
3. Upload the **contents** of this folder (`index.html`, `css/`, `js/`, `languages/`, and supporting files) to the root of the GitHub repository used for GitHub Pages.
4. Enable GitHub Pages in the repository settings.
5. Open the published URL and test desktop, tablet and mobile layouts before sharing a QR code.
