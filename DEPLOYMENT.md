# Publishing the TB Journey

These files are arranged to match the current GitHub repository, where `index.html`, `style.css`, `game.js` and `content.js` sit in the root. Please keep them there unless you also update the paths in `index.html`.

1. Download and extract the project ZIP.
2. In the GitHub repository, make a backup of the current version.
3. Upload the files from this folder to the repository root. Choose to replace the existing versions of files with the same names. Do not upload the ZIP itself.
4. Commit the changes.
5. In **Settings → Pages**, check that publishing is enabled for the `main` branch and the root folder (`/`).
6. Wait for the deployment to finish, then open the Pages link and hard-refresh with `Ctrl + Shift + R`.

Check the home page, all three roles, the choices and their feedback, the score screen, the language selector, and the layout on a phone. If the page looks unstyled, first confirm that `style.css` is in the root beside `index.html`.
