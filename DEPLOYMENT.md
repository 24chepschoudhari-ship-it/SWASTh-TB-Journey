# Deployment

## Run and deploy the standalone simulator

1. Extract the ZIP.
2. Open `index.html` locally and test the full experience.
3. Upload the **contents** of this folder (`index.html`, `css/`, `js/`, `languages/`, and supporting files) to the root of the GitHub repository used for GitHub Pages.
4. Enable GitHub Pages in the repository settings.
5. Open the published URL and test desktop, tablet and mobile layouts before sharing a QR code.

## Before iGEM publication

- This ZIP is a **standalone GitHub Pages app**. Do not embed the GitHub Pages site as an external iframe in the official iGEM wiki or make the wiki load its CSS/JavaScript from GitHub Pages. If you want the game to run inside the official 2026 wiki, adapt the files to the official team repository and follow the current iGEM-hosted asset workflow. Check the wiki deliverables guide before publishing.
- The official iGEM 2026 deliverables page currently lists the Wiki and Attributions Form deadline as **21 October 2026**. Confirm the exact deadline and submission status in your team's Deliverables Dashboard.
- Test all three roles and check that every choice leads to a valid scene or the biology section.
- Check the per-choice points and the final score screen in a complete run, then replay with different options to confirm the score updates.
- Check the interface in English, Hindi, Marathi and Gujarati. The story scenes currently remain in English; the role-selection screen says so.
- Ask the team to verify the scientific wording and have an appropriate TB/diagnostic expert review it.
- Review `AI_ASSISTANCE.md` and complete any disclosure/attribution required by the current iGEM rules.
- Confirm the final way this simulator is linked, embedded or hosted meets the current 2026 iGEM communication and wiki requirements. A GitHub Pages build is not, by itself, a certification of iGEM wiki compliance.
- Do not claim clinical validity or educational impact without supporting evidence.
